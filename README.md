## 🏆 Featured Projects

### 🛡️ CreditGuard — Explainable Credit Risk Assessment
XGBoost loan-default classifier that explains itself: SHAP decomposes every prediction into feature contributions, and the decision threshold is tuned on validation data to weight recall — in lending, a missed defaulter costs more than a false flag.

**Result:** ROC-AUC **0.939** · default-class F1 **0.81** (vs 0.65 logistic baseline) · 6,305-application held-out test set
**Deployed:** FastAPI backend + JS frontend, live on Render

### 🏠 Room Type Predictor — NYC Airbnb
End-to-end ML pipeline classifying 48,895 NYC Airbnb listings into 3 room types — ColumnTransformer preprocessing, 4 classifiers benchmarked, Random Forest tuned via RandomizedSearchCV, shipped as a production FastAPI + JavaScript app.

**Result:** **85.6% accuracy** · **0.742 macro F1** (3-class, imbalanced)
**Deployed:** FastAPI backend + JS frontend, live on Render
